# Real-Time Chat Application

A Real-Time Chat Application developed using Frontend Development technologies such as HTML, CSS, and JavaScript.

This project provides a modern and responsive chat interface where users can send and receive messages instantly with an interactive UI design.

# Features

- Real-Time Chat Interface
- Responsive User Interface
- Send and Receive Messages
- Auto Reply System
- Interactive Chat Layout
- Clean Frontend Design
- Mobile Responsive Design
- Modern UI Using CSS


# Technologies Used

- HTML5
- CSS3
- JavaScript
